# متجر الفولي لخدمات الدش والستالايت (Storefront)

واجهة متجر إلكتروني وخدمات فنية احترافية متكاملة لـ **"الفولي لخدمات الدش"** مبنية بأحدث تقنيات الويب:
**React 19 + TypeScript + Vite + Tailwind CSS v4 + Three.js 3D + Framer Motion**.

---

## 🛰️ مميزات المتجر والتنفيذ التقني

1. **الكتالوج المعتمد ومطابقة الـ Schema**:
   - تم الالتزام الكامل بملف التكوين `elpholy-ai-storefront-brief.json` وحفظ كافة معرفات الأقسام (11 قسم)، المنتجات، والصور كما هي.
   - احترام جميع الـ **Feature Flags**:
     - `price`: مفعل (عرض الأسعار بالجنيه المصري ج.م).
     - `salePrice`: مفعل (حساب نسبة الخصم وعرض السعر المخفض مع شطب السعر الأصلي).
     - `description`: مفعل (عرض الوصف الدقيق لكل منتج).
     - `stock`: غير مفعل (عدم إظهار كميات المخزون كما هو محدد).
     - `checkout`: غير مفعل (توجيه الشراء السريع والاستفسارات مباشرة عبر واتساب مع رسالة منسقة تلقائياً، مع دعم جاهز لـ Cart & Order Submission إلى `POST /public/stores/elpholy/orders` فور تفعيل الميزة في لوحة الـ SaaS).

2. **عناصر وتفاعلات ثلاثية الأبعاد (3D Components)**:
   - **SatelliteHeroCanvas**: مشهد ثلاثي الأبعاد تفاعلي كامل مبني بـ Three.js لطبق دش بارابوليك حقيقي مع ذراع LNB، موجات إشارة كهرومغناطيسية متحركة في الفضاء، قمر صناعي مصغر يدور في المدار، وتتبع تفاعلي لحركة الماوس ومؤشر جودة الإشارة (99% نايل سات 301).
   - **TiltCard**: تأثير منظور وإضاءة عاكسة 3D لبطاقات الأقسام والمنتجات.
   - **InteractiveDishGuide**: حاسبة ستالايت ذكية تفاعلية تمكن العميل من اختيار نوع التركيب (منزل، دش مركزي لعمارة، كافيه، فيلا) والقمر الصناعي (نايل سات، هوتبيرد، بدر، أسترا) لحساب مقاس الطبق ونوع الـ LNB والمواصفات المثالية بنقرة واحدة.

3. **الربط والتواصل الرسمي**:
   - **زر واتساب عائم (Floating WhatsApp)**: مرتبط مباشرة بالرقم `01004803335` مع نافذة محادثة منبثقة تفاعلية وحلقات نبض حركية.
   - **رابط صفحة فيسبوك الرسمية**:
     `https://www.facebook.com/alfwly.lkhdmat.aldsh/?locale=ar_AR` مدمج ببانر احترافي في قلب الصفحة ومربوط بالفوتر والنافبار.
   - **حجز فني صيانة ميدانية**: نافذة منبثقة متخصصة لحجز موعد فني للمنزل مع تأثيرات احتفالية Confetti وتجهيز رسالة الحجز.

4. **لوحة الألوان المعتمدة (Palette)**:
   - Egyptian Blue: `#283793`
   - Space Indigo: `#25213B`
   - Carrot Orange: `#F49013`
   - Lavender: `#E8E4F1`
   - Ghost White: `#F5F3FA`

5. **اللغة والاتجاه**:
   - عربي بالكامل (Arabic Only) مع اتجاه `dir="rtl"` وخط `Cairo` العربي الأنيق من Google Fonts.

## 🚀 التشغيل والتطوير (Getting Started)

### 1. تثبيت الحزم (إذا لزم الأمر)
```bash
npm install
```

### 2. تشغيل السيرفر المحلي (Development)
```bash
npm run dev
```

### 3. بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```

### 4. معاينة نسخة الإنتاج محلياً (Preview)
```bash
npm run preview
```

## 🌐 التوافق مع SaaS و Cloudflare

- تم ضبط تطبيق الواجهة ليكون مستقلاً ومجهّزاً للنشر المباشر على **Cloudflare Pages** أو أي استضافة ثابتة.
- لا يتم استدعاء أو كشف أي مفاتيح خاصة أو Admin APIs.
- التطبيق يقوم تلقائياً بمحاولة جلب الكتالوج المباشر من نقاط النهاية العامة (`/public/stores/elpholy`) ويعتمد تلقائياً على البيانات الأولية المضمّنة عند عدم توفر الاتصال لضمان سرعة تحميل فائقة وتجربة مستخدم مستقرة 100%.
